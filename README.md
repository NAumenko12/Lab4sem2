## Задание 1. Нелинейное уравнение

Вариант 2:

```text
2x^2 + cos(x) = 6
```

Функция:

```text
f(x) = 2x^2 + cos(x) - 6
```

Точность:

```text
epsilon = 10^-4
```

В программе выполняется:

- отделение корней;
- уточнение корней методом половинного деления;
- уточнение корней методом Ньютона;
- уточнение корней методом простых итераций;
- вывод таблиц итераций;
- сравнение методов по скорости сходимости.

Отделенные интервалы:

```text
[-2; -1.5]
[1.5; 2]
```

Найденные корни:

```text
x1 ≈ -1.7588
x2 ≈  1.7588
```

Метод половинного деления выводит таблицу:

```text
N    a_n    b_n    b_n - a_n
```

Метод Ньютона и метод простых итераций выводят таблицу:

```text
N    x_n    x_n+1    x_n+1 - x_n
```

## Задание 2. Вычисления в массивах

Вариант генератора:

```text
ranlux24_base
```

В программе выполняется:

1. Создается массив из `n` чисел, где `n >= 10`.
2. Массив заполняется случайными целыми числами из диапазона `[100; 150]`.
3. Находится второй по величине элемент массива.
4. Вычисляется сумма элементов между минимальным и вторым по величине элементом.
5. Создаются массивы `arr1` и `arr2` со случайными числами из диапазона `[-50; 50]`.
6. Создается массив `arr3`:

```text
arr3[i] = arr1[i] + arr2[i], если i четный
arr3[i] = arr1[i] - arr2[i], если i нечетный
```

7. Подсчитывается количество повторений каждого уникального элемента первого массива.
8. По заданному диапазону лет выводятся високосные годы.

## Задание 3. Последовательность псевдослучайных чисел

Вариант 3:

```text
Генератор Фибоначчи с запаздыванием
```

Используется формула:

```text
S_n = (S_{n-a} operation S_{n-b}) mod m
```

где:

- `a`, `b` — положительные целые лаги;
- `operation` — операция `+`, `-`, `*`, `^`;
- `m` — модуль;
- `n = max(a, b)`;
- `N` — количество генерируемых чисел.

Пример 1:

```text
a = 2, b = 1, operation = +, m = 16
Начальные значения: S0 = 1, S1 = 4
Вывод: 5 9 14 7 5 12
```

Пример 2:

```text
a = 1, b = 3, operation = -, m = 10
Начальные значения: S0 = 5, S1 = 8, S2 = 3
Вывод: 8 0 7 9 9 2
```

## Задание 4. Теория голосований

На выборах участвуют кандидаты и избиратели. Каждый избиратель задает полное ранжирование кандидатов от самого предпочтительного до наименее предпочтительного.

Реализованы два метода:

- метод Борда;
- метод Кондорсе.

### Метод Борда

Если всего `n` кандидатов, то кандидат на первом месте получает `n - 1` баллов, на втором `n - 2`, и так далее до `0` баллов за последнее место.

Побеждает кандидат с наибольшей суммой баллов.

### Метод Кондорсе

Для каждого кандидата проводится парное сравнение с каждым другим кандидатом. Победитель Кондорсе — кандидат, который выигрывает у всех остальных кандидатов в парных сравнениях.

Если такого кандидата нет, выводится:

```text
не определён
```

Пример:

```text
3
3
A B C
5 A B C
6 B C A
4 C A B
```

Результат:

```text
По Борду: B (17 очков)
По Кондорсе: не определён
```
